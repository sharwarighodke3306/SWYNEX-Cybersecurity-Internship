# SWYNEX Technologies – Cybersecurity Internship

## Task 4: Security Assessment Report

### Project Description

This project presents a DVWA-based Security Assessment conducted as part of the Cybersecurity Internship at SWYNEX Technologies. It documents the local lab setup, testing observations, identified configuration limitations, assessment findings, and defensive security recommendations.

### Project Overview

This project documents a baseline security assessment of DVWA (Damn Vulnerable Web Application) in a local Windows environment using XAMPP.

### Activities Performed

- Local DVWA environment setup
- Database configuration
- Security-level configuration
- SQL Injection baseline observation
- Reflected XSS baseline observation
- File Upload interface inspection
- CSRF form inspection
- Evidence collection
- Security assessment report preparation
